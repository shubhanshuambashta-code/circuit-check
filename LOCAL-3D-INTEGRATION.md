# Local 3D integration

Integrated the 3D contribution from repository commit d68c9ff into the existing local app. Use Design review > 3D. Existing saved geometry can show representative package previews. Rerun checks to produce a native GLB where KiCad can export one; only supplied or resolvable assigned models are included. Arbitrary GLBs lack verified component mapping; use geometry preview for finding locations. Original circuits, data directory and Groq settings are preserved. Extension v0.6.4 remains unchanged and has no 3D feature.
