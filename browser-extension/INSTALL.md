# Install / update v0.6.4

1. Extract Circuit-Check-Multi-platform-v0.6.4.zip into a permanent folder.
2. Chrome/Edge → Extensions → Developer mode → Load unpacked → select the folder containing manifest.json.
3. To update: replace the existing installed folder's files, click Reload on its extension card, accept added site access if requested and refresh circuit tabs. The badge shows v0.6.4.
4. For live browser circuits, open the supported site and click the extension icon → Check circuit.
5. For desktop programs, export/save a supported circuit file, then choose its software in Import a simulator circuit and open/paste the file. The extension's Details → Extension options opens file review in a full browser tab.
6. Open visual workspace uses the same tab. Use browser Back to return.

Keep the same installed folder to preserve the local library. If installing as a separate extension, export/import the previous review library. See README.md for exact formats and coverage.
