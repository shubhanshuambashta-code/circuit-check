# CircuitCheck frontend design source

Adapted from **AI Sales Copilot Landing Page / Halyard Copilot Landing**, by Kedhareswer Naidu (2026).

- Listing: https://21st.dev/@kedhareswer/templates/ai-sales-copilot-landing-page
- Source archive: https://kedhar-components.pages.dev/source/halyard-copilot-landing.zip
- Retrieved: 14 November 2026
- Licence: MIT; original notice preserved at `public/licenses/halyard-MIT.txt` and copied into production builds.

`src/template.css` retains the template stylesheet and `src/TemplateSky.tsx` retains its SVG orbital background and grain. `src/Landing.tsx` adapts the layout and interactions to CircuitCheck. The original system font stack, steel palette, gradients, rails, pill controls, orbit motion, product tilt and scroll reveals are retained. The sales simulation, fabricated business metrics, testimonials and sales forms are replaced with supported CircuitCheck content and the existing functional review interface. No additional frontend dependencies or framework migration were required.

Local mode continues to use the existing API. GitHub Pages continues to use the existing explicitly labelled recording of native results; it cannot execute native checks or accept live design edits.
